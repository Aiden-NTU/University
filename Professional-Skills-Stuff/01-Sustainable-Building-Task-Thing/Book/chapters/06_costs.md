# Cost analysis

## Hypothetical budget and build-up

The brief asks teams to set a hypothetical budget so features stay consistent [@ntu_brief]. We
adopted about **£2.4 million** for the whole project, built up as follows:

Table: Hypothetical capital budget

| Package | Basis | Indicative £ |
| --- | --- | ---: |
| Construction (shell and core) | 720 m² GIA × about £2,800/m² (education-building order of magnitude from published cost services) [@bcis_indicative] | 2,016,000 |
| Fit-out (priced catalogue items) | Itemised from the 3D room model | 88,270 |
| Roof PV array | about £1,000/kWp × 49 kWp | 49,000 |
| Plant allowance (heat pump, MVHR, battery, thermal store, rainwater) | Quotes still required; provisional sum | 200,000 |
| **Working total** |  | **about 2,353,000** |

Fit-out is the part we can price in detail today. Every chair, desk, LED panel and sensor is
counted from the model; unit rates are indicative supplier prices pending quotes. Furniture and
IT dominate the priced total; major plant is still unpriced because its size depends on the
heating model.

## Running costs and budget check

Electricity is costed at **24.5 p/kWh** (DESNZ non-domestic average including CCL, Q2 2026) and
grid carbon at **0.131 kgCO₂e/kWh** [@desnz_qep2026; @desnz_ghg2026].

Table: Annual electricity picture (modelled so far)

| Flow | kWh/yr | £/yr at 24.5 p | tCO₂e/yr |
| --- | ---: | ---: | ---: |
| Roof PV generation | 46,924 | 11,496 (value if used on site) | 6.1 avoided |
| Lighting (design) | 4,021 | 985 | 0.5 |
| Other equipment (non-IT) | about 2,340 | about 570 | 0.3 |
| Server IT load | 105,120 | 25,754 | 13.8 |
| Space heating / ventilation fans | *to be modelled* | — | — |

**Arguments for the costs.** The shell-and-core figure is large, but it buys a permanent learning
building and a landscape upgrade on a plot the university already owns. PV payback against avoided
grid electricity is comparatively short. Lighting savings of about £3,650/yr show that controls
matter even before plant is finalised.

**Arguments against / risks.** Server electricity dominates running cost if it is counted fully
against the building; net-zero operation is only plausible if that IT load is treated as a campus
computing service whose heat is a by-product, and if heating demand is shown to match the recovered
heat. Parking revenue of roughly £29,000/yr (see [[Introduction and site]]) is not fully replaced
by PV value alone. Construction at £2,800/m² is a benchmark, not a tender. Until plant is quoted
and an energy model exists, the £2.4 million envelope should be treated as a planning budget, not
a fixed price.
